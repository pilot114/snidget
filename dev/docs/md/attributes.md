Конфигурация в Snidget - это атрибуты PHP 8 прямо в коде: никаких YAML, XML и отдельных файлов роутинга.
Фреймворк находит размеченные классы сам, по директориям приложения и модулей.

### Route

`Snidget\HTTP\Route` - HTTP роут. Цель: метод контроллера или класс контроллера (для префикса).

    #[Route(prefix: 'api/v1')]                          // на классе
    #[Route(regex: 'post/(?<id>\d+)', method: 'GET')]  // на методе

- `regex` - регулярное выражение URI без слэшей по краям, именованные группы становятся параметрами действия
- `prefix` - общий префикс роутов класса, вместе с `regex` не задается
- `method` - HTTP метод, по умолчанию `GET`

Ищется в: _HTTP/Controller_. Подробнее - в разделе "HTTP".

### Bind

`Snidget\HTTP\Bind` - привязка посредника. Цель: класс или метод, атрибут повторяемый.

    #[Bind(class: Api::class, method: 'create', priority: 10)]

- `class`, `method` - на посреднике: контроллер и действие, к которым он привязан (без них - ко всем).
На контроллере: класс и метод посредника, которого нужно подключить
- `priority` - чем больше, тем раньше выполняется слой, по умолчанию `0`

Ищется в: _HTTP/Middleware_ и на контроллерах. Подробнее - в разделе "HTTP".

### Assert

`Snidget\Kernel\Assert` - правило валидации. Цель: публичное свойство DTO, атрибут повторяемый.

    #[Assert(minLength: 4, maxLength: 24, pattern: '/^\w+$/')]
    public string $login = '';

- `min`, `max` - границы числа
- `minLength`, `maxLength` - границы длины строки (в символах, а не байтах)
- `pattern` - регулярное выражение, которому должна соответствовать строка
- `notBlank` - значение не может быть `null` или пустой строкой

Значение не того типа - тоже ошибка: число не проскочит мимо проверки длины, а строка - мимо `min` и `max`.
Проверяет DTO целиком `Assert::validateType($dto)`, возвращая ошибки по полям, а для JSON запросов
проверка выполняется автоматически (см. "Валидация входных данных").

### Column

`Snidget\Database\SQLite\Column` - колонка таблицы. Цель: публичное свойство DTO.

    #[Column(name: 'id', type: Type::INTEGER, autoincrement: true)]
    public ?int $id = null;

- `name` - имя колонки
- `type` - тип SQLite (`Snidget\Database\SQLite\Type`), по умолчанию `TEXT`
- `isNull` - разрешить `NULL`, по умолчанию колонка `NOT NULL`
- `autoincrement` - `PRIMARY KEY AUTOINCREMENT`
- `default` - значение по умолчанию

Подробнее - в разделе "Базы данных".

### Command

`Snidget\CLI\Command` - консольная команда. Цель: публичный метод класса.

    #[Command('Creates a new user')]
    public function run(TestInput $data): void

- `description` - описание для списка команд и автодополнения

Ищется в: _Command_. Подробнее - в разделе "CLI".

### Arg

`Snidget\CLI\Arg` - опция или аргумент команды. Цель: публичное свойство DTO команды.

    #[Arg('beta option', short: 'b')]
    public ?string $beta = null;

- `description` - описание для автодополнения
- `isOption` - `true` (по умолчанию) для опции, `false` для позиционного аргумента
- `short` - короткое имя опции из одной буквы

Подробнее - в разделе "CLI".

### Listen

`Snidget\Kernel\PSR\Event\Listen` - подписка на событие. Цель: метод класса, атрибут повторяемый.

    #[Listen(KernelEvent::ERROR)]
    public function onError(Throwable $data): void

- `event` - вариант любого перечисления (enum)

Ищется во всем _App_. Подробнее - в "Списке событий".

### Атрибуты PHP

Кроме своих, фреймворк использует встроенные атрибуты языка - их стоит взять на вооружение и в приложении:

- `#[\Override]` - метод обязан переопределять метод родителя, иначе ошибка компиляции
- `#[\NoDiscard]` - предупреждение, если результат вызова не использован. Им помечены методы неизменяемых
объектов (`Response::withHeader()`, `Collection::map()`), где потерянный результат - почти всегда ошибка
